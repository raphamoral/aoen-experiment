# Scripts legados

Scripts de geração de gráficos usados em versões anteriores do trabalho.

**Não os use.** Eles contêm os valores das séries **cravados no código**, e
esses valores não correspondem a nenhum dos arquivos consolidados deste
repositório. Foram substituídos por `gerar_figuras_v4.py` e
`gerar_figuras_restantes.py`, que leem os números de `consolidated_v4.json` e
das tabelas do trabalho.

Mantidos apenas como registro de como as figuras antigas foram produzidas.
